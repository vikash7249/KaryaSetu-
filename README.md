# KaryaSetu — AI Work OS

## Stack
- Frontend: React 18 + TailwindCSS
- Backend: Node.js + Express + MongoDB
- Auth: JWT + Domain-locked security
- AI: OpenAI GPT-4

## Quick Start (AWS)
```bash
# Backend
cd backend && npm install
cp .env.example .env   # fill values
npm start

# Frontend
cd frontend && npm install
npm run build
```
